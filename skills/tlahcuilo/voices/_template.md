# Voice register — TEMPLATE

A register is an **overlay on the base fingerprint** (`writing-voice/my-voice.md`), not a
replacement. Write only what CHANGES for this scenario. The base still governs word choice,
punctuation tics, and rhythm; the register dials the situational knobs below.

Copy this to `voices/<name>.md` and fill each knob as a diff: "same as base EXCEPT …".

## Knobs

- **Audience** — who reads this and what they need from it.
- **Person** — `I` / `we` / `you` / imperative. (Blog leans `I`; team strategy leans `we`
  + imperative; guidelines lean `you`/imperative.)
- **Formality** — how far above or below the base's default register.
- **Hedging** — allowed, or stripped? (Decision docs strip it; exploratory essays allow it.)
- **Directness** — blunt, or diplomatic? How opinions land.
- **Structure density** — prose-heavy vs headings/bullets/tables. How much scaffolding.
- **Asides** — parenthetical/discursive tangents kept (blog) or cut (standards)?
- **Length discipline** — terse to the bone, or room to breathe?
- **Opening / closing move** — how a piece of THIS type should start and end.

## Keep from base (do not sand off)

List the base tics that must survive into this register — the things that make it *him* even
when the register is formal. (e.g. short declarative landings, no promotional adjectives.)
